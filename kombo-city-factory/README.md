# مصنع كومبو سيتي للفيديوهات القصيرة

مصنع لإنتاج فيديوهات Shorts تعليمية باللهجة المصرية لقناة **رواة الواقع**، باستخدام مفاتيح الخدمات الموجودة بالفعل في GitHub Actions Secrets.

## مسار الإنتاج

1. اختيار أول فكرة غير مستخدمة من `ideas.csv`.
2. توليد سيناريو JSON باللغة المصرية عبر Gemini.
3. توليد ست صور سينمائية عبر Hugging Face Inference Providers (FLUX.1-schnell) أولًا، مع الرجوع إلى Pollinations عند الفشل إذا كان مفتاحه متاحًا؛ اللقطات 1 و3 و5 للمقدم كومبو، واللقطات 2 و4 و6 توضيحية بلا أشخاص.
4. إنشاء التعليق الصوتي عبر Fish Audio باستخدام `FISH_VOICE_ID`.
5. إنشاء ترجمة SRT وحرقها على الفيديو.
6. تركيب فيديو عمودي 1080×1920، بمعدل 30 إطارًا/ثانية، ومدة مستهدفة 45 ثانية، مع حركات كاميرا وانتقالات.
7. فحص الفيديو قبل تسجيل الفكرة كمستخدمة.
8. نشر الفيديو علنًا على قناة YouTube بعد التحقق من هوية القناة، ثم حفظ الفيديو والبيانات وإيصال النشر داخل المستودع.

## الأسرار المطلوبة

أضف الأسرار التالية من **Settings → Secrets and variables → Actions**، باستخدام حساباتك ومفاتيحك الحالية:

- `GEMINI_API_KEY`
- `FISH_API_KEY`
- `FISH_VOICE_ID`
- `HF_TOKEN` (اختياري لكنه المفضل لتوليد الصور عبر Hugging Face)
- `POLLINATIONS_API_KEY` (اختياري كمسار احتياطي)
- `YT_TOKEN_JSON`
- `YT_CLIENT_ID`
- `YT_CLIENT_SECRET`

لا تضع أي قيمة سرية داخل الملفات أو السجلات، ولا تشاركها في المحادثة. استخدام Hugging Face Inference Providers قد يُحاسب حسب المزود والطلب؛ راجع الرصيد والأسعار في حساب Hugging Face. Pollinations يبقى احتياطيًا عند ضبط مفتاحه.

## التشغيل

من **Actions → Kombo City Factory → Run workflow**:

- `generate_and_publish`: الخيار الافتراضي؛ ينشئ فيديو جديدًا ثم يحاول نشره.
- `publish_latest`: ينشر أحدث فيديو محفوظ لم يسبق تسجيل إيصال نشر له، دون إنشاء فيديو جديد.

تعمل الجدولة تلقائيًا عند الساعة 08:00 بتوقيت القاهرة، مع فحص التوقيت الصيفي والشتوي.

## الملفات

- `ideas.csv`: بنك الأفكار.
- `used.txt`: سجل الأفكار التي اكتمل إنتاجها.
- `main.py`: منطق الإنتاج والتحقق.
- `prompts/system_prompt.txt`: تعليمات السيناريو والهوية البصرية.
- `publish_youtube.py`: النشر والتحقق من القناة.
- `output/`: ملفات الفيديو والبيانات وإيصالات النشر.

## حدود تقنية

- المشاهد الست صور ثابتة تتحرك بالكاميرا؛ ليست رسومًا متحركة ثلاثية الأبعاد فعلية ولا تتضمن مزامنة شفاه.
- Pollinations وGemini وFish Audio خدمات خارجية؛ توافرها وحدودها تتبع حسابات المستخدم وسياسات المزود.
- GitHub Actions المجاني له حدود تشغيل وتخزين.
- لا تُسجّل الفكرة كمستخدمة إلا بعد نجاح إنشاء ملف الفيديو واجتياز فحوصه.
