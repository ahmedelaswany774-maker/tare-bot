# Hakewina Agent Engine

Additive scaffold for حكاوينا | قصص واقعية. Existing rendering, Fish Audio, OAuth, and upload workflows are intentionally untouched.

## Agents
1. Story Hunter: three human-interest candidates, source leads, uncertainties, and duplicate check.
2. Storyteller: write only from verified facts; warm Arabic narration, immediate hook, scenes, lesson.
3. Packaging: three truthful titles, description, tags, thumbnail brief (max three words).
4. Shorts: source-supported vertical adaptation, 30–60 seconds.
5. Quality + Memory: evidence gate, duplicate registry, stage tracking.
6. Production/Publishing: later integration with existing renderer/uploader.

## Editorial gates
- Real stories only; label material inspired by real events.
- At least two independent sources before verification.
- Never invent dialogue, private thoughts, dates, or scenes.
- Keep confirmed facts separate from disputed claims.
- Public upload remains disabled until an end-to-end dry run succeeds.

## First milestone
Create a SQLite story registry, reject duplicate story fingerprints, and track idea → research → verified → script → packaging → shorts → production → published.
